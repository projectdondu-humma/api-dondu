RESTful API service untuk platform donasi uang dan barang layak pakai. Menangani manajemen otentikasi multi-role, validasi inventaris barang, integrasi payment gateway, dan pencatatan riwayat transaksi keuangan.

---

## 🛠️ Tech Stack & Requirements
* *Language & Framework:* PHP 8.2+ / Laravel 11
* *Database:* MySQL 8.0+
* *Authentication:* Laravel Sanctum
* *Payment Gateway:* Midtrans (Snap / Core API Sandbox)
* *API Documentation:* Postman Collection / Swagger
